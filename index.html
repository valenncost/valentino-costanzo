01

REMLAB

E-commerce · Impresión 3D

remlab3d.com
El problema
Una pieza impresa en 3D no se entiende en una foto plana: hay que verla de todos lados.
Qué hice
Una tienda donde una impresora imprime el logo mientras bajás, y cada pieza se puede girar en 3D. Catálogo, carrito y pedidos a medida.
Resultado
Publicada, con 27 productos en el catálogo. Sigue en desarrollo: lo próximo es el pago online.
  • Next.js
  • TypeScript
  • Tailwind
  • three.js

02

Importado Bahía

E-commerce + sistema a medida · Perfumería

importadobahia.com
El problema
Un catálogo grande de perfumes, con frascos, decants y precios mayoristas, difícil de mostrar y de vender por chat.
Qué hice
La tienda con vitrina, filtros y carrito, el seguimiento de cada pedido por link y un panel para manejar pedidos, stock y clientes.
Resultado
Es la tienda real de la marca: toma los pedidos, el stock se descuenta solo y el dueño lo maneja desde el celular.
  • HTML
  • CSS
  • JavaScript
  • Supabase
  • GSAP
Ver importadobahia.com ↗
03

torino

Sistema a medida · Ticketera propia

torinoprod.com
El problema
Vender entradas sin depender de una ticketera ajena ni de capturas de transferencia.
Qué hice
La ticketera completa: pago con Mercado Pago, entrada con QR al instante, panel con ventas en vivo y escáner para la puerta, que anda sin señal.
Resultado
Las fiestas de torino se venden desde su propia web, con entradas a nombre de cada persona.
  • HTML
  • CSS
  • JavaScript
  • Supabase
  • Mercado Pago
Ver torinoprod.com ↗
04

Contadores Asociados

Web · Estudio contable en Paraguay

Contadores Asociados
El problema
Un estudio contable de Encarnación necesitaba una web para presentarse y recibir consultas.
Qué hice
Una landing con los colores de la marca, sobre la referencia que eligió el cliente: servicios, proceso, preguntas frecuentes, mapa y consulta por WhatsApp.
Resultado
Terminada y entregada, lista para publicarse en el dominio del estudio.
  • HTML
  • CSS
  • JavaScript
